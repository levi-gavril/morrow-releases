# Morrow

A better way to begin tomorrow. Morrow is a calm Christian wake-up app, made for Romania, in English and Romanian.

This repository only holds the installers. Download the newest version from the [latest release](../../releases/latest).

| Installer | For |
|---|---|
| `Morrow-Setup-x64.exe` | Most Windows PCs (64-bit, Windows 10 and 11) |
| `Morrow-Setup-arm64.exe` | Windows on ARM (Snapdragon and other ARM laptops) |
| `Morrow-Mac-arm64.dmg` | Macs with Apple silicon (M1 to M5) |
| `Morrow-Mac-x64.dmg` | Macs with an Intel processor |

The iPhone app is coming to the App Store.

## Installing

The installers are not code-signed yet.

- **Windows:** if Windows says it protected your PC, choose More info, then Run anyway. Morrow installs for your user only and updates itself when a new version is published here.
- **Mac:** open the .dmg and drag Morrow to Applications. If macOS says Morrow cannot be opened, go to System Settings, then Privacy & Security, and choose Open Anyway. On a Mac, download each new version from here.

Everything Morrow keeps stays on your own device.
